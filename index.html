What the tool does

A small bridge for private development files.

This operator-controlled utility uses rclone and a bounded local transfer helper to store and retrieve Sizemet iOS development archives, supporting files and test evidence in a dedicated private Google Drive folder. Xcode, active source files and the build tools needed for current work remain on the Mac.

  1. Select and authorise

    The operator authorises specific files and the dedicated archive folder through Google. The connection requests selected-file access (drive.file), not access to the whole Drive.

  2. Transfer when needed

    The local helper lists authorised archive items, uploads uniquely named packages or downloads a requested package into a new local destination. It does not mirror or automatically synchronise the entire Drive.

  3. Verify before cleanup

    Checksums confirm retrieved files and download-back verification checks new uploads. Local disposable copies are cleared only through a separate, authorised cleanup process after verification.

Clear boundaries

Public explanation.
Private archive.

This utility is intended for the operator's private development workflow, not public customer sign-up. Publishing these pages does not share the Google Drive folder or release the iOS app.

Selected-file permission is not a permanent permission for every future file in a folder. Files added through another app may require explicit selection before this utility can access them.

These pages are separate from Sizemet's main product website and do not replace that website's homepage or privacy policy.
